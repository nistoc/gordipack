# Методика «память → запросы»: четыре сорта фактов

Одна страница. Применяется к каждой строке записанной памяти роли при её сжатии.
Цель: **хранится только то, что не может быть спрошено; всё спрашиваемое — спрашивается.**
Факт, который перечитывается запросом при каждом чтении, не может протухнуть по построению.

## Сорта и правила

| сорт | признак | что делать |
|---|---|---|
| **(а) запрашиваемое** | число, статус, список, у которого есть (или может быть) команда: счёт карточек, объём долга ленты, состав ролей, права, версия схемы, состояние репозитория | ЗАМЕНИТЬ строкой «бери запросом: `<команда>`». Замена засчитывается ТОЛЬКО если команда прогнана и её ответ совпал с удаляемым текстом — «можно спросить» без прогона не считается |
| **(б) оплаченный урок** | правило поведения, купленное ошибкой; часто содержит численный пример | ОСТАВИТЬ. Протухающее число внутри урока получает якорь: «на момент замера <дата>». Урок не удаляется ради объёма НИКОГДА — это самая дешёвая и самая дорогая ошибка сжатия |
| **(в) якорь-провенанс** | хэш коммита, дата решения, номер записки/карточки — неизменяемое прошлое | ОСТАВИТЬ как есть. Неизменяемое не протухает; удалять его — терять след |
| **(г) приказ** | что делать преемнику; может содержать имена таблиц/полей/флагов | ОСТАВИТЬ. Каждое имя поля в приказе — только проверенное ИСПОЛНЕНИЕМ (неверное имя даёт правдоподобный ноль, а не отказ). Приказ, дублирующий машинный слой, понижается до ссылки на слой |

| **(д) сверяемое с миром** | список файлов, перечень каталогов, имена таблиц и схем — не спросишь у координационной базы, но спросишь у диска и стенда (`ls`, `find`, один SELECT) | СВЕРИТЬ при разборе. Особый режим отказа — ЗАНИЖЕНИЕ: список, отставший в меньшую сторону, выглядит скромным и безопасным, но «графы у 8 баз» при 16 отправляет искать вручную то, что уже есть. Занижающий список опаснее отсутствующего: отсутствие заставляет посмотреть, занижение — нет. (Сорт предложен ролью по итогам раската: из 9 её настоящих находок 5 были этого сорта) |

Строка, не попавшая ни в один сорт, — **спорная**: она называется в таблице вердиктов
отдельно и НЕ решается молча.

Служебный сорт **«связка»** (заголовки, пустые строки, нумерация шагов) — не факты;
без него счёт строк не сходится ни на одной реальной секции (уточнение №1 по пилоту).

## Примеры (обезличенные, из живой памяти ролей)

- (а) «дерево чисто, неотправленного нет» → строка удаляется: это печатает слой диска
  при каждом чтении. «карточек открыто 14» → «бери запросом: `backlog.py list --role <Р>`».
- (б) «указатель врал тем сильнее, чем крупнее долг (замер <дата>: 542 записки)» —
  остаётся; число несёт якорь даты.
- (в) «починено коммитом `abc1234`, приёмка проверена двумя нарочными поломками» — остаётся.
- (г) «фильтровать личное — таблицей адресатов, НЕ колонкой способа адресации» — остаётся;
  имена в нём проверены исполнением при записи.

## Порядок работы по секции

1. Каждой строке — вердикт (а/б/в/г/спорная) в таблицу, поимённо.
2. Счёт сходится: строк = а + б + в + г + спорных.
3. Замены (а): команда прогнана, ответ совпал — только потом строка удаляется.
4. После секции — прогон проверялки памяти: сжатие не должно рождать новых кандидатов.
5. Числа до/после (символы) — в отчёт.

## Холостой прогон перед записью — не формальность

Сохраняй правленую секцию сперва вхолостую и читай ПОДПИСЬ, которую печатает инструмент.
Помимо отказов, она даёт **дельту размера до записи** — и это первый честный вопрос
к собственному ремонту: «на сколько выросло и почему». Роль, увидевшая 5331 → 8439,
перечитала правку целиком, а не только вставленный кусок (наблюдение принесено
из раската; в правило-стандарт НЕ вынесено сознательно — это польза механизма,
а не признак состояния памяти).

## Границы, названные заранее

- Методика решает по СМЫСЛУ строки, а не по тому, ловит ли её проверялка: «не подгоняй
  текст под прибор» действует в обе стороны.
- Сжатая память обязана остаться СВЯЗНЫМ ТЕКСТОМ, а не лесом ссылок: если после замен
  секция перестала читаться глазами — сжатие зашло за цель.
- Чужую память сжимает её владелец; чужой рукой — только механические замены сорта (а),
  с честным авторством в журнале и уведомлением.
