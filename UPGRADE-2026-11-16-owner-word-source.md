## Зачем этот выпуск

```
беда ............ критерий ① карточки #554 требует у слова владельца ссылку на файл-источник с номером строки.
                  Ключи --source-file и --source-line у owner-word.py add были необязательны, и инструмент адреса
                  сам не брал: у эталона на 16.11 у 20 слов из 20 номера строки не было, у 17 — и файла

                  из той же находки, что и час; уже записанным словам адрес дописывает команда source

## 1. Что изменилось

```
vnext/prototype/find-owner-word.py ...... под КАЖДОЙ строкой «чат:» находки (и набранной, и выбранной в окне) —
                                          строка «   файл: <полный путь>:<номер строки с 1>». Прочий вывод прежний
vnext/prototype/owner-word.py ........... add: адрес — из находки, с которой сверен час. Нет строки «файл:» у этой
                                          находки — ОТКАЗ, код 2, слово не записано (рядом старый искатель).
                                          Адрес, названный ключами, только сверяется: расхождение — отказ, код 2.
                                          Новая команда source [номера] [--apply]: тем же поиском дописывает адрес
                                          записанным словам; без --apply — холостой прогон; записанный файл или номер
                                          строки, расходящийся с найденным, не перезаписывает, а называет; код 1 —
                                          у части слов адрес не найден (каждое названо номером с причиной)
приёмка (новая) ......................... vnext/prototype/bite-owner-word-source.py — 3 случая, 3 нарочные поломки
```
⚖️ Почему отказ, а не громкая строка: текст и час найдены той же строкой записи, значит адрес у искателя есть;
его пропажа — расхождение двух инструментов, а не нехватка данных. Громкая строка оставила бы хранилище
пополняться словами без адреса.

```
· многострочный текст: адрес — строка записи, где лежит ПЕРВАЯ строка текста; если строки текста лежат
  в разных строках записей, это только печатается («записываю адрес первой»)
· запись разговора, сжатая или удалённая после записи слова: source назовёт слово, но адреса не восстановит
· вид исхода находки (выбор в окне без выбранного варианта) не судится — карточка #778
