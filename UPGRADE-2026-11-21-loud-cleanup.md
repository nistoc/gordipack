## Зачем этот выпуск

```
беда ............ приёмки убирали свой временный каталог вызовом shutil.rmtree(path, ignore_errors=True). На Windows
                  открытый файл и файл «только чтение» удаление срывают, а отказ глушился: каталог оставался, и ни
                  вывод, ни код выхода об этом не говорили. Молчащее удаление стояло в 63 местах 36 файлов. Замер
                  на main 55ee759: из 34 приёмок остаток оставили 6, одна — копию базы координации целиком
                  (у эталона 165 МБ) после КАЖДОГО прогона
что теперь ...... уборку делает помощник mezo_stand.remove_tree(): чего убрать не смог — называет одной строкой
                  вывода; причина каждого найденного остатка исправлена в самой приёмке. Замер после правки —
                  раздел 4
```

## 5. Чего выпуск НЕ делает

```
· строка об остатке не меняет вердикт и код выхода приёмки: по ней никто не падает. Кому остаток нужен провалом —
  судит возвращённое remove_tree() значение False сам
· приёмка, остановленная по потолку времени или упавшая до уборки, каталог по-прежнему оставит: его уносят срок
  хранения стендов (mezo_stand.py) и уборка janitor-stands.py, как раньше
· каталоги bite-finder-hang-* и bite-finder-resolve-* срок хранения стендов не знает, как и до правки: их имена
  в перечень известных начал не добавлялись
· двенадцать файлов bite-callform-*.db, *.db-shm и *.db-wal (около 2 МБ), оставленных ПРЕЖНИМИ прогонами
  bite-call-form-counterexample.py в корне временной папки, выпуск не убирает: срок хранения стендов берёт только
  каталоги. Новые прогоны их больше не создают; старые можно удалить рукой
· два места в find-owner-word.py оставлены молчащими намеренно — раздел 1
· на системе, отличной от Windows, занятый файл удалению не мешает: случаи с ним не ставятся, и о поведении
  уборки там этот выпуск ничего не утверждает
· молчащее удаление в СОБСТВЕННЫХ файлах контура (не из пакета) новая приёмка не судит: из каталогов контура
  она печатает найденные места для сведения, случай о классе там «не поставлен»
· общий прогон guard-all.py остаток временных каталогов не считает: мерка этого выпуска — прогон приёмок
```
