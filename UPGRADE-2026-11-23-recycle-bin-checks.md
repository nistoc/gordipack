## 2. Что увидит контур

Новые строки печатает уборка стендов по сроку (и любой, кто зовёт помощник рукой). Каждая — про один каталог:

```
⛔ не перенесено в Корзину, каталог не тронут: <путь> — путь внутри — N знаков UTF-16, а Windows берёт
   в Корзину не длиннее 259 (самый длинный: <путь>); Корзина такой каталог не берёт, Windows стёрла бы его насовсем
⛔ не перенесено в Корзину, каталог не тронут: <путь> — записи Корзины не читаются: <каталог> (<ошибка>)
⛔ УДАЛЕНО МИМО КОРЗИНЫ: <путь> — каталога нет на месте, а записи с его прежним путём в Корзине не появилось:
   вернуть его из Корзины нельзя. Перенос остальных остановлен
⚠️ каталога нет на месте, а приход в Корзину не проверен: <путь> — новая запись Корзины не прочитана.
   Перенесённым не засчитан, перенос остальных остановлен
⏸ не перенесено, каталог не тронут: <путь> — перенос остановлен: <причина>
```

Сводная строка уборки прежняя: каталог с любым из этих исходов входит в её число «не перенесено».

⚠️ **Стенд с путём от 260 знаков внутри уборка по сроку больше не уберёт никогда**: каждый час он получает отказ
и строку выше. Убирать такие стенды — рукой человека, утилитой `janitor-stands.py --apply` (она удаляет
насовсем, мимо Корзины, и говорит это сама). Прежде такие стенды тоже исчезали насовсем, но молча и под словом
«в Корзину».

⚠️ Строка «УДАЛЕНО МИМО КОРЗИНЫ» значит, что каталог уже потерян: помощник ловит это ПОСЛЕ переноса и
останавливает остальные. Причины, кроме длинного пути, у эталона не встречались; если строка появилась —
пришлите её PROTO контура-эталона.

```

Ожидаемо — код 0 и последняя строка `ИТОГ: случаев прошло 8 из 8 · провалено: нет · не проверено: нет · поломок
поймано 9 из 9`. Настоящая Корзина в приёмке только читается: перенос в неё не зовётся, на одной поломке Windows
стирает каталог приёмки с длинным путём — в Корзину он не ложится.

```
① ①б ..... запись $I с прежним путём — засчитан; ①б — каталог назван коротким именем 8.3, запись несёт полное

③ ④ ...... записи нет — «УДАЛЕНО МИМО КОРЗИНЫ»; запись незнакомого формата — «приход не проверен»;
           в обоих второй каталог тем же помощником не тронут
⑤ ........ записи Корзины не читаются — отказ, перенос не звался
⑥ ........ настоящая уборка по сроку через _windows_bin: старый стенд с путём 260 знаков — отказ, стенд на месте,
