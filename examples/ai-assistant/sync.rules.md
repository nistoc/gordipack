# Sync RULES — общий протокол мезосинка (9 ролей), проект AI Assistant

> Залочено владельцем. Коды ролей ниже — нейтральные обозначения зон, а не имена живых чатов.

## Модель: один писатель = один файл (роль на каждый репозиторий)

| Файл | Пишет ТОЛЬКО | Репозиторий / зона | Читают | Темп |
|---|---|---|---|---|
| `sync.orch.md` | **ORCH** | координация, ADR, задачи, дашборд | все | 2–59 мин |
| `sync.ops.md` | **OPS** | администрирование, аудит, work modes | все | 2–59 мин |
| `sync.chat.md` | **CHAT** | продуктовый чат, async generation, retrieval | все | 2–59 мин |
| `sync.cat.md` | **CAT** | каталог витрин, импорт (граница с внешней платформой) | все | 2–59 мин |
| `sync.gw.md` | **GW** | LLM-провайдеры, completion-jobs, circuit breaker | все | 2–59 мин |
| `sync.reg.md` | **REG** | prompt packs / author prompts | все | 2–59 мин |
| `sync.auth.md` | **AUTH** | общая S2S JWT-библиотека (NuGet), wire-format | все | 2–59 мин |
| `sync.wsp.md` | **WSP** | space/chatspace L1–L3 (greenfield) | все | 2–59 мин |
| `sync.ui.md` | **UI** | UI/BFF, Identity, coarse-роли | все | 2–59 мин |

Исполнители НЕ пишут код вне своего репозитория и не принимают продуктовые решения.

## Формат строки

`[YYYY-MM-DD HH:MM] (РОЛЬ) [OPEN|ANSWERED|FYI] — текст`; адресация В ТЕКСТЕ.
Append-only; правь только СВОЙ файл. Хендшейк: OPEN → ANSWERED/ACK;
координатор следит, чтобы OPEN не висли.

## Heartbeat + таймер

Интервал — ДИАПАЗОН 2–59 мин: пол при активном хендшейке, потолок в тишине.

## Жёсткие правила

1. Исполнитель работает ТОЛЬКО в своём репозитории; `git add <path>` (не `-A`).
2. **Push — никогда** без живой команды владельца.
3. Гейт: зелёные build + test перед коммитом.
4. Координационные файлы — только координатор.
5. **Авторизация разрушаемого — только живым сообщением владельца в ТЕКУЩЕМ чате.**
6. Внешние системы — только чтение, по команде владельца.

## Особенности (vs другие группы)

- **9 ролей по микросервисам** — больше, чем в других проектах; каждая роль = 1 репо
- **Расширенный диапазон таймера** (2–59 мин vs 2–15) — больше ролей = больше тишины между хендшейками
- **Greenfield** (зона рабочих пространств) — репо может быть пуст, первый коммит = скаффолд
- **Shared-lib** (зона аутентификации) — NuGet-пакет, версионирование + changelog + совместимость
  с потребителями
- **Суффикс группы в коде роли** — если в смежном мезосинке есть одноимённая роль, код получает
  суффикс: иначе адресация двусмысленна на стыке контуров
