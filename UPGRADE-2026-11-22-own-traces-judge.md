Нарочная поломка у шести приёмок, судящих функциями помощника, ставится в КОПИИ пакета на стенде, в обеих копиях
`mezo_stand.py`: суду возвращается прежний способ, и провалиться обязан ровно встречный случай «-а». Три правки:

```python
# 1. в ask_traces() строку
        return _own_traces(db, marks, tails), ""
#    заменить на
        found = _StateDict(_own_traces(db, marks, tails))
        found.state = _file_state(db)
        return found, ""

# 2. в traces_verdict() перед последней строкой «return ("traces" if grown else "clean"), grown, ""» вставить
    if not grown and getattr(before[0], "state", None) != getattr(after[0], "state", None):
        return "traces", grown, ""

# 3. в конец файла дописать
class _StateDict(dict):
    state = None


def _file_state(db):
    out = []
    for name in (str(db), str(db) + "-wal"):
        try:
            st = os.stat(name)
            out.append((st.st_size, st.st_mtime_ns))
        except OSError:
            out.append(None)
    return tuple(out)
```

⚠️ Прогон под такой поломкой проваливается, а стенды провалившегося прогона приёмка по построению оставляет
для разбора. У эталона после одного прогона осталось: `bite-milestone-step-set.py` — десять стендов, около
1,4 ГБ; `bite-rule-expiry.py` и `bite-issue-loop.py` — по одному, около 160 МБ. Запускайте с отдельной временной
папкой и уберите её после. Правку копии `mezo_stand.py` верните сразу: с ней провалится каждый следующий прогон
этих шести приёмок.
