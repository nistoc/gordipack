## Зачем этот выпуск

`--skip` сверял имя только у проверок, которые общий прогон зовёт отдельным инструментом (`utc`, `drift`,
`чтение ленты` и др.), и у трёх замеров памяти — общим именем «память». Встроенные проверки самого
`guard-all.py` имя не сверяли: снятая всё равно выполнялась, её провал входил в код выхода, а вывод молчал.
Так было у восьми проверок с прямым итогом и у замеров без итога (раздел 1). Имя, которого в прогоне нет
(опечатка), тоже проходило молча — человек думал, что снял проверку, а снято не было ничего.
Нашла приёмка выпуска 09.10 (`bite-local-dir.py`): чтобы отделить код выхода местных проверок от проверок
пакета, ей пришлось обходить `--skip`. В документе 09.10 это записано в разделе 7 — этим выпуском снято.

## 1. Что изменилось

```
--skip <имя> ............. снимает ЛЮБУЮ проверку по имени, как его печатает прогон (--full печатает каждую).
                           Снятая печатает строку «⏭️ <имя> — пропущен по --skip»; своей строки и своего
                           вклада в код выхода у неё нет. Имена через запятую, как прежде
восемь встроенных ........ хронология id · отметки прочитанного: регистр · сохранённая память: регистр ·
                           отметки прочитанного: реестр · форма вызова: источники · фантомные .db ·
                           журнал схемы · замороженные md — снимаются по имени (раньше — никак)
замеры без итога ......... пересказ измеримого · сохранённая память: свежесть / содержание / посекционно —
                           по имени; «память» по-прежнему снимает три замера памяти разом, а теперь их
                           можно снимать и по одному: память: кандидаты на устаревание · память: прежние
                           слова · память: объём. Первый снимается и тем видом, каким его строку печатает
                           сам замер: «память: кандидатов на устаревание». Имена трёх замеров называет --help
мост соседей ............. три проверки моста читают одни папки — снимаются ВМЕСТЕ любым из трёх имён:
                           мост соседей · мост: записки без разбора · мост соседей: вопросы без ответа
незнакомое имя ........... строка «⚠️ --skip «<имя>»: проверки с таким именем в этом прогоне не было —
                           пропускать было нечего · ближайшие: …». Близких имён нет — вместо
                           «ближайшие» подсказка «имена — как печатает прогон (--full печатает каждую)».
                           Код выхода от неё не меняется
местная · перечень ....... по --skip не снимается нарочно, как прежде (кривой перечень чинят, а не прячут);
                           теперь говорит об этом строкой «⚠️ --skip «местная · перечень»: эта проверка
                           по --skip не снимается нарочно»
«местных проверок нет» ... строка с --full теперь без знака «ℹ️» (знак «🗂»). Документ 09.10, раздел 4.2,
                           называл её «ℹ️ местных проверок нет» — там пометка; вторая пометка в нём — в
                           разделе 7: строка о --skip снята этим выпуском. Зачем:
                           приёмка bite-brief-views.py (случай ⑧) требует, чтобы строки со знаками «⚠️» и
                           «ℹ️» в кратком и полном виде совпадали, а эта печатается только с --full. С выпуска
                           09.10 приёмка проваливалась на любом контуре без local/checks.json — у эталона тоже
```

⚠️ **Если ваш вызов `--skip` где-то называл имя, которого нет**, — теперь вы увидите строку «⚠️ --skip «…»».
У эталона так нашлись две приёмки пакета: `bite-neighbour-asks.py` и `bite-answer-overwritten.py` передавали
«ленты» вместо «чтение ленты» — поправлены в этом выпуске. Проверьте свои вызовы в скриптах и в памяти
ролей: имя из строки «ближайшие» — скорее всего то, что имелось в виду.

## 2. Какие файлы меняются

```
.mezosync/scripts/guard-all.py ................ сверка имени с --skip в общих функциях проверки, строка
                                                о незнакомом имени, текст --help, знак строки
                                                «местных проверок нет»
vnext/prototype/bite-guard-skip.py ............ НОВАЯ приёмка: 30 случаев, из них 8 нарочных поломок
vnext/prototype/bite-local-dir.py ............. совместимость с новым guard-all.py (проходит и со старым)
vnext/prototype/bite-neighbour-asks.py ........ имя «чтение ленты» в --skip
vnext/prototype/bite-answer-overwritten.py .... то же
```
Приёмки (`vnext/prototype/`) обновление приносит, только если файл уже лежит во втором каталоге установки
(ключ `prototype_install_dir`, документ 09.10). Новую `bite-guard-skip.py` оно не ставит: её не зовёт ни
один скрипт. У эталона план показал «≠» у трёх файлов: `guard-all.py`, `bite-neighbour-asks.py`,
`bite-answer-overwritten.py`.

## 4. Как убедиться, что встало

```
а) python <КОНТУР>/.mezosync/scripts/guard-all.py --skip "нет такой проверки"
   → строка «⚠️ --skip «нет такой проверки»: проверки с таким именем в этом прогоне не было …»
б) python <КОНТУР>/.mezosync/scripts/guard-all.py --full --skip "журнал схемы"
   → строка «⏭️ журнал схемы — пропущен по --skip», строки «✅ журнал схемы» нет
в) из клона пакета — испытуемой копией берутся инструменты ВАШЕГО контура (обновление эту приёмку
   не ставит, раздел 2):
        MEZO_CONTAINER=<КОНТУР> python <клон пакета>/vnext/prototype/bite-guard-skip.py
   → первая строка «⚖️ испытуется: ЖИВОЙ контур», последняя «✅ ИТОГ: 30 из 30». У эталона ≈5 мин:
   десять общих прогонов на копии вашего контура; живая база только читается (снимок). Переменную
   MEZO_FORBID_LIVE=1 здесь НЕ ставить — с ней приёмка откажет, потому что испытывает живые инструменты
```

## 5. Известно и в этом выпуске НЕ сделано

- Остальное из раздела 7 документа 09.10 — без изменений (правки `rules-from-pack.py`, `check-rules-mirror.py`,
  `guard-rights-registry.py` ждут следующего выпуска).
- Строка о незнакомом имени не меняет код выхода: опечатка в `--skip` не валит прогон, а только называется.
  Так сделано нарочно — иначе старый вызов с давно переименованной проверкой уронил бы общий прогон у
  соседа на ровном месте.
- Строка того же рода, что «местных проверок нет», осталась у моста соседей: «ℹ️ мост соседей […]: «…» —
  НАШЕ письмо старого вида …» печатается тоже только с `--full`. Приёмка `bite-brief-views.py` её не видит:
  на её копии таких писем нет. Контур, у которого они есть, получит на этой приёмке провал случая ⑧ —
  это не поломка выпуска, а тот же долг; правка — следующим выпуском (карточка #679).
