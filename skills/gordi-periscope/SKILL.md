# gordi-periscope — поднять Перископ контура (для координатора)

Перископ — локальная служба, читающая базу координации ОДНОГО контура, и окно поверх неё. Поднимает координатор контура по просьбе владельца; каждый контур — свой экземпляр. `<КОНТУР>` — каталог с `.mezosync/mezosync.db`; `<ПАКЕТ>` — клон пакета gordipack этого контура.

## Шаги

1. **Контур**: иди от текущего каталога вверх до `.mezosync/mezosync.db`. Нет — навык не применяется.
2. **Живое правило** `periscope-viewer` главнее навыка. Две команды:
   ```
   python <КОНТУР>/.mezosync/scripts/set-rule.py --key periscope-viewer --show
   python <КОНТУР>/.mezosync/scripts/rules-from-pack.py --show periscope-viewer
   ```
   - **взято** — первая печатает текст контура: следуй ему; статус «СНЯТО» или текст «ОТОЗВАНО» — не поднимай, спроси владельца;
   - **не взято** — первая: «ERR: правила … нет»; вторая печатает текст пакета (справка): поднимай по нему и скажи, что контур правило не принял;
   - **пакет не найден** — добавь `--source <ПАКЕТ>` (каталог: `db-q.py "SELECT value FROM meta WHERE key='template_checkout'"`);
   - **нигде нет** — остановись, скажи владельцу.
3. **Подъём** (строки запуска, флаги, форма записей — из правила):
   1. В `<ПАКЕТ>` есть `src/Gordi.Periscope.Api` и `srcclient`; есть dotnet и node; нет `srcclient/node_modules` — один раз `npm install --prefix <ПАКЕТ>/srcclient`.
   2. **Занятые порты и чья там база.** Слушающие порты: Windows `Get-NetTCPConnection -State Listen`, иначе `ss -ltn`. К слушающим (прежде всего 5177, 5173 и названные владельцем):
      ```
      curl -g -s -m 3 http://127.0.0.1:<порт>/api/health
      curl -g -s -m 3 "http://[::1]:<порт>/api/health"
      ```
      Окно (Vite) бывает слушает только `[::1]`. `activeDbPath` называет показываемую там базу.
   3. **Свой уже поднят** (записи в `<КОНТУР>/.claude/launch.json`, порты отвечают с базой этого контура) — второй раз не запускай, сразу пункт 7.
   4. **Свободная пара**: порт службы и порт окна — разные, не занятые соседями и (лучше) не умолчания пакета.
   5. **Две записи** `periscope-api` и `periscope-ui` в `<КОНТУР>/.claude/launch.json` (файла нет — создай; чужие записи не трогай); окну — `VITE_API_PORT` = порт службы.
   6. **Запуск по имени**: сначала `periscope-api`, потом `periscope-ui` (`preview_start`).
   7. **«База своя» после каждого подъёма**: `/api/health` у службы и через окно (`http://127.0.0.1:<порт окна>/api/health`, иначе `[::1]`). Нужно: `activeDbPath` = `<КОНТУР>/.mezosync/mezosync.db`, `readOnly` true, `status` ok. Путь чужой — `preview_stop` обеих, смени порты; иное — останови и покажи ответ целиком. Владельцу: `http://localhost:<порт окна>`, вкладка «Задачи», путь базы и что Перископ живёт до перезагрузки машины или приложения (чат можно закрыть).

## Границы (правило строже — следуй ему)

- только чтение, наружу не выставлять;
- живёт до перезагрузки машины или приложения, в котором поднят (Claude Desktop — само приложение); после перезагрузки — поднять заново;
- поднимает координатор по просьбе владельца, только свой контур и свою базу; чужой порт на свою базу не переключать;
- разрешение среды запускать службу (Claude Desktop — «Expose Local Services») — решение владельца: проси, не обходи;
- гасить только своё (`preview_stop`), не по имени процесса.

## Чего навык не делает

Не клонирует и не чинит пакет, не ставит dotnet и Node.js; не пишет в свод, ленту, карточки и базу; не «берёт» правило из пакета. Тело правила не копируется: копия разойдётся со сводом.
