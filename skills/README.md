# skills/ — навыки host-уровня

Навыки, которые ставятся НЕ в контур, а на машину владельца (`~/.claude/skills/`),
и работают в любом чате любого контура gordi на этой машине.

| Навык | Что делает |
|-------|-----------|
| [`gordi-owner-reply`](./gordi-owner-reply/SKILL.md) | перед ответом владельцу разворачивает ЖИВОЕ правило формы ответа из свода того контура, где идёт чат |

## Установка

Скопируй каталог навыка в `~/.claude/skills/`:

```
cp -r skills/gordi-owner-reply ~/.claude/skills/
```

## Чем host-навык отличается от навыка контура

Навык контура (например `atlas-owner-reply` в `<контур>/.claude/skills/`) СОБИРАЕТСЯ
из свода этого контура механизмом `rules-to-skills.py` и несёт полные тексты правил —
но виден только в чатах под каталогом контура. Host-навык видим везде и полного текста
НЕ несёт (вторая редакция расходится со сводом молча) — он находит контур по
`.mezosync/mezosync.db` вверх от текущего каталога и читает правило живым запросом.
Есть у контура свой собранный навык — host-навык уступает ему.

Парный хук, который напоминает о форме БЕЗ вызова навыка, в каждый ход:
[`hooks/owner-reply-reminder.json`](../hooks/owner-reply-reminder.json).
