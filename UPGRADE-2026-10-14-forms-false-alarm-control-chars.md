## Зачем этот выпуск

**Ложная тревога проверки форм вызова (разбор COORD, карточка #680).** `guard-launcher-forms.py` запускает команды,
записанные в памяти ролей, и судит ответ. Признаки отказа — «Traceback», «unrecognized arguments», «invalid choice»,
«expected one argument», «the following arguments are required» — она искала подстрокой во ВСЁМ выводе. Механизм,
печатающий текст, печатает и чужие слова: `read-phoenix.py` выводит память роли, а в памяти PROTO эталона стоит
пояснение «отказ «unrecognized arguments»». Проверка красила `read-phoenix.py`, ответивший кодом 0: «🔴 МЕХАНИЗМ
НЕ ЗНАЕТ ЭТОЙ ФОРМЫ:» с пустым пояснением. Приёмка `bite-launcher-forms.py` отбирала формы для случая ⑤ подстрокой
«x.py» (её ловит и read-/save-phoenix.py) и судила общий итог — 12–13.10 она провалилась три прогона подряд,
и каждый провал сохранял 38–40 стендов, 6–7 ГБ (стенд — временный каталог с копией базы, сохраняемый при провале
для осмотра).

**Папки координации в проверке невидимых управляющих байтов (предложение AIA, карточка #715, пункт 4).**
`guard-control-chars.py` без аргументов смотрел только каталоги инструментов. Общий прогон проверок зовёт его без
аргументов — папки, где роли пишут записи и письма, на невидимые байты не проверялись вовсе; AIA держала для них
местную обёртку.

## 3. Порядок для вашего контура

```

1 ... план:
        python <КОНТУР>/.mezosync/scripts/update-tools.py --rev 2740aaf
      ожидаемо «≠» у тех файлов раздела 2, что стоят во втором каталоге; у эталона — ровно 3 строки «≠».
      «✋» у файла раздела 2 — вы правили его у себя: остановитесь и пришлите вывод
2 ... запись, второй план — до «+ ≠ ≈» нет:
        python <КОНТУР>/.mezosync/scripts/update-tools.py --rev 2740aaf --apply
        python <КОНТУР>/.mezosync/scripts/update-tools.py --rev 2740aaf
3 ... шагов схемы нет — шаг 2 раздела 3 UPGRADE.md пропустите
4 ... проверки (из второго каталога установки):
        python <каталог приёмок>/guard-control-chars.py --selftest
      → «самопроверка: все 23 контрастов прошли»
        python <каталог приёмок>/guard-control-chars.py
      → первой строкой «каталог не назван — беру по умолчанию: …» — в перечне ваши папки coordination и bridges.
      ⚠️ Если у вас стои́т местная обёртка для этих папок (у AIA — в local/), сперва сравните её находки с этим
      прогоном; убирать её — после совпадения
        python <каталог приёмок>/bite-launcher-forms.py
      → «✅ ПРОВЕРКА ПРИНЯТА — случаев 20, различающих 19»; у эталона ≈4,5 мин
```

⚠️ Первый общий прогон проверок после установки впервые смотрит папки координации. Невидимый байт в старой записи
или письме даст провал этой строки — это находка, а не поломка выпуска: файл и байт названы в выводе, лечение —
`--unescape` или `--fix` (шапка `guard-control-chars.py` объясняет, какое когда).
