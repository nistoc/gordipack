### Общий прогон: строка о сверке тел

`guard-all.py` зовёт `verify-install.py` (рядом, та же база, предел 60 с) и печатает ОДНУ строку по коду выхода команды. Строка исход
не меняет: ни код выхода общего прогона, ни число провалов. Причина: запись хранит отпечаток версии ПАКЕТА, и правка контура, принятая
установщиком (`--accept-merge`), читается командой как порча — провал проверки сломал бы общий прогон соседям с такими правками.

```
код 0 ............ «✅ сверка тел установленных файлов: совпало — сверено файлов: N»
                   если среди файлов есть «имя другое, тело то же»: «⚠️ сверка тел: тела совпали, но N файлов лежат под другим именем —
                   файла под именем записи нет» и путь команды для разбора
                   если в выводе команды нет строки итога с числом сверенных файлов (файл команды пуст или подменён):
                   «сверка тел НЕ ВЫПОЛНЕНА: команда вернула код 0, но строки с числом сверенных файлов в её выводе нет —
                   это не ноль» и путь команды для вызова вручную
код 1 ............ если последняя строка вывода команды начинается с «ИТОГ: РАСХОДИТСЯ — »: «⚠️ сверка тел: РАСХОДИТСЯ — …» и полный путь
                   команды для разбора; иначе (непойманная ошибка в самой команде): «сверка тел НЕ ВЫПОЛНЕНА: команда вернула код 1,
                   но строки итога в её выводе нет — … это не ноль» и путь для вызова вручную
код 3 ............ «⚠️ сверка тел: нечем сверять — <причина>»
иначе, команды
нет рядом, предел
времени .......... «сверка тел НЕ ВЫПОЛНЕНА: <почему> — это не ноль»
```

В строках кода 1, кода 3 и «не выполнена» нет знака прохода и слов «совпало» и «прошло»; слово «РАСХОДИТСЯ» стоит только там, где команда сама напечатала итог о расхождении.

## 5. Чего выпуск НЕ делает

```
· не ставит службу GordiWall в чаты ролей: сборка и подключение службы — отдельный шаг контура, этот выпуск лишь меняет её исходники
· не закрывает карточку 818 (установщик при обновлении не двигает час записи установки: template_recorded_at остаётся часом первой
  записи): поле installed.at службы по-прежнему несёт этот час, граница названа в источнике поля
· сверка тел отличает порчу от принятой правки контура ТОЛЬКО словами выпуска, не машиной: запись хранит отпечаток версии пакета,
  поэтому `--accept-merge` даёт «тело изменено»; поэтому строка в общем прогоне — предупреждение, а не провал
· сверка тел не видит смены одних окончаний строк и хвоста файла: это граница отпечатка, она названа в выводе и в справке команды
· база в режиме WAL: читающее соединение команды оставляет рядом два служебных файла (-shm и -wal); файл базы не меняется. Параметр
  immutable команда не ставит
· набор ядра (core-bites.txt) расширен двумя строками; общий список ядра и приёмки других предметов не пересматривались
· приёмка bite-guard-verify-line.py идёт около 18 минут. В наборе ядра (bite-all.py --set core, потолок 1800 с на приёмку) она
  проходит; общий запуск bite-all.py без --set держит потолок 300 с и назовёт её «не запустилась — потолок времени»: зовите её
  отдельно или с ключом --timeout 900
```
