## Зачем этот выпуск

Две находки приёмок не автором.

**Доставка правил до подсказок (находка OPSSRE, записка #5840, «М4»).** Сборка нового контура (`init-group.py`,
блок 6в) зовёт шаг `20260904-rule-skill-delivery.py --fill-undecided`: он ставит `skill_delivery='yes'` правилам,
названным в пакетах. Шаг печатал «✅ проставлено yes: N», где N — длина ПЛАНА, а не число строк, которые правка
задела. Сборка судила шаг только по коду выхода. OPSSRE сломала правку нарочно (условие `AND 0`): шаг вышел
с кодом 0 и «✅ проставлено yes: 56», в базе осталось «не решено: 65», сборка сказала «готово», а приёмка
`bite-fresh-circuit.py` (37 случаев) поломку не заметила. В чистой сборке правка не промахивается (56 из 56);
опасность — в том, что промах не был бы виден.

**Хрупкий случай ④ приёмки `bite-signal-templates.py` (находка PROTO, записка #5845).** Приёмка снимает копию
базы с живого контура. Если у COORD в этот момент есть живое объявление о правке, случай ④ («держишь» про чужую
карточку — отказ) получал код 0 вместо отказа: печатник честно видел объявление адресата. Прогон давал 28 из 29
ровно на ④ — случай судил живые данные, а не печатник.
